# Screenshots

Capturas de pantalla utilizadas como evidencia de las prácticas realizadas en el Linux Homelab.

---

## Objetivo

Utilizar capturas para complementar la documentación técnica cuando una imagen permita demostrar claramente un resultado.

---

## Ejemplos

Se pueden documentar:

- Instalación.
- Configuración de VirtualBox.
- Estado de servicios.
- Configuración de red.
- Resultados de comandos.
- Paneles de monitoreo.
- Pruebas de conectividad.

---

## Organización

Las capturas pueden organizarse utilizando nombres descriptivos.

Ejemplo:

```text
screenshots/
├── installation/
├── networking/
├── security/
└── monitoring/
```
