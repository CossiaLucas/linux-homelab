# Backups

Documentación relacionada con las estrategias de backup del Linux Homelab.

---

## Objetivos

Practicar:

- Creación de backups.
- Compresión.
- Automatización.
- Organización de respaldos.
- Verificación.
- Restauración.

---

## Conceptos

Un backup es una copia de información que permite recuperar datos ante pérdida, corrupción o eliminación accidental.

El laboratorio permitirá experimentar con diferentes métodos de respaldo.
