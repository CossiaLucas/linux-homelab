# Scripts

Scripts utilizados para automatizar tareas del Linux Homelab.

---

## Objetivos

Practicar automatización mediante Bash y desarrollar herramientas reutilizables para administración de sistemas.

---

## Posibles scripts

Ejemplos de tareas que podrán automatizarse:

- Obtener información del sistema.
- Crear usuarios.
- Crear grupos.
- Realizar backups.
- Verificar servicios.
- Verificar espacio en disco.
- Revisar conectividad.
- Generar reportes.
