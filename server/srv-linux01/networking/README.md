# Networking

Documentación relacionada con la configuración y diagnóstico de red de `srv-linux01`.

---

## Objetivos

Practicar:

- Interfaces de red.
- Direcciones IP.
- Máscaras.
- Gateway.
- DNS.
- Rutas.
- Conectividad.
- SSH.
- Diagnóstico de problemas de red.

---

## Información de red

La configuración inicial utilizará NAT mediante VirtualBox.

La configuración real deberá registrarse después de la instalación.
