# Troubleshooting

Registro de problemas, diagnósticos y soluciones relacionados con `srv-linux01`.

---

## Objetivo

Utilizar el Homelab para desarrollar una metodología práctica de troubleshooting.

El objetivo no es solamente solucionar problemas, sino aprender a identificar síntomas, formular hipótesis, recopilar evidencia y verificar soluciones.

---

## Metodología

```text
1. Identificar el problema
        ↓
2. Reproducirlo
        ↓
3. Recopilar información
        ↓
4. Formular hipótesis
        ↓
5. Realizar pruebas
        ↓
6. Aplicar solución
        ↓
7. Verificar
        ↓
8. Documentar
